El método

Complex 180 combina fuerza y resistencia en el mismo plan de entrenamiento: no hay que elegir entre levantar pesado o aguantar el ritmo, se entrenan las dos cosas juntas, cinco días por semana. La planificación se renueva cada mes y se adapta a dos niveles — OPEN y PRO — para que el mismo método sirva tanto para quien empieza con orden como para quien ya entrena y busca más exigencia.

Preguntas frecuentes

Lo que suelen preguntar antes de arrancar.

¿Necesito equipamiento especial?

El plan está pensado para gimnasio. Si entrenás en casa, contanos qué tenés disponible y lo adaptamos.

¿Es para principiantes?

Sí. El nivel OPEN está pensado justo para eso: construir base con orden. El nivel PRO es para quien ya entrena.

¿Cómo recibo el plan cada mes?

Entrás a tu perfil con tu clave personal y ahí está la planificación del mes, lista.

¿Puedo cambiar de nivel más adelante?

Sí, cuando estés listo para pasar de OPEN a PRO (o al revés) lo vemos juntos.
